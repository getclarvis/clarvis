# Agents and extensions

Agent Profiles are Markdown definitions in `<global>/agents/` or `<workspace>/.clarvis/agents/`; their grants still meet the run's immutable ceiling. Extension Profile definitions live in each scope's `extension-profiles/` directory. An Extension Profile selects exact installed plugin and standalone skill identities. A definition on disk is not selected merely because it exists. Workspace executable inputs can also be withheld until their exact bytes are trusted. Container placement has its own restricted extension view.

Standalone skills use `SKILL.md`; plugins may contribute skills and other capabilities. Workflow definitions live in each scope's `workflows/` directory and follow their own parser and activation path. Use the Extensions interface to inspect installed identities, selected membership, and trust state. A skill written during a run is not injected into that run's captured catalog. A successful reviewed write requests a safe refresh, so a subsequent run can see the new skill when selected by the effective Extension Profile. Changes to selected profile, provider or placement can report reconnect required; do not describe a saved file as already active.
